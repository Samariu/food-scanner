First-time setup

  1. Open your Google Sheet
  2. Go to Extensions → Apps Script
  3. Paste the contents of apps_script.gs
  4. Replace YOUR_SPREADSHEET_ID with your sheet ID (the long string in the URL)
  5. Click Deploy → New deployment → Web app
  6. Set "Execute as: Me" and "Who has access: Anyone"
  7. Authorize when prompted, then copy the URL here
